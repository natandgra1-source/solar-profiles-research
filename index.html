About This Repository

Methodology, data sources, and technical details

Overview

This repository is an open-source data resource developed by the GOAL Lab at Georgia Institute of Technology. It provides hourly electricity load profiles and solar generation profiles for 174 countries, intended for use in energy system modeling, grid planning, and electrification research.

Solar Generation Profiles

Solar profiles are generated using pvlib with real historical weather data from Open-Meteo (2023 archive). Each country uses a representative centroid coordinate.

POA irradiance calculated via pvlib.irradiance.get_total_irradiance() using GHI, DNI, and DHI from Open-Meteo. Output is AC power in watts, shifted to approximate local solar noon using UTC offset. Profiles are provided for 16 time snapshots: 4 seasonal (Jan 1, Apr 1, Jul 1, Oct 1) and 12 monthly (1st of each month).

Load Profiles

Hourly electricity demand profiles are normalized so that 1.0 = daily average demand, allowing comparison across countries regardless of total consumption. Profiles cover 99 countries and include seasonal snapshots (winter, spring, summer, autumn) representing typical demand shapes. Values above 1.0 indicate peak demand periods; values below 1.0 indicate off-peak periods.

City Solar Profiles

Solar generation profiles are also available for 522 cities across 174 countries, enabling sub-national comparison. The same pvlib methodology and Open-Meteo weather data are used, with each city's specific latitude/longitude coordinates.

Data Sources
☀️
Open-Meteo Archive API
Historical hourly solar irradiance (GHI, DNI, DHI), temperature, and wind speed — 2023 full year, UTC. Free and open access, no API key required.
🔬
pvlib (Python)
Open-source PV modeling library used for solar position, POA irradiance decomposition, cell temperature, and DC/AC conversion following PVWatts V8 methodology.
⚡
GOAL Lab Load Dataset
Country-level normalized hourly electricity demand profiles compiled for energy access and grid modeling research.
Repository

Source code and CSV data files are openly available on GitHub. The generation scripts (gen_openmeteo_solar.py) can be re-run to refresh data or extend coverage.
